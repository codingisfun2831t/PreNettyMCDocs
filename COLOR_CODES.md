# Color Codes

Every string rendered by the client allows color codes. In Classic they start with the ampersand (`&`, ACSII character 38) but in Beta and beyond they start with the section character (`§`, ACSII character 167). They are followed by a hex digit (0-9, A-F). The colors are as follows:

| Code | Name         | Color   |
| ---- | ------------ | ------- |
| &0   | Black        | #000000 |
| &1   | Dark Blue    | #0000C0 |
| &2   | Dark Green   | #00C000 |
| &3   | Dark Teal    | #00C0C0 |
| &4   | Dark Red     | #C00000 |
| &5   | Purple       | #C000C0 |
| &6   | Gold         | #C0C000 |
| &7   | Gray         | #C0C0C0 |
| &8   | Dark Gray    | #404040 |
| &9   | Blue         | #4040FF |
| &a   | Bright Green | #40FF40 |
| &b   | Teal         | #40FFFF |
| &c   | Red          | #FF4040 |
| &d   | Pink         | #FF40FF |
| &e   | Yellow       | #FFFF40 |
| &f   | White        | #FFFFFF |
